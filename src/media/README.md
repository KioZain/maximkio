# Ролики

Сюда кладутся **мастера** — то, что пришло из записи экрана или из монтажа:
`mp4`, `mov`, `m4v` и `gif`.

Гифку сюда класть можно и нужно. Наружу она всё равно уедет роликом и
похудеет в несколько раз: GIF хранит кадры целиком и знает 256 цветов,
поэтому весит кратно больше того же куска видео. Качество от перегона не
улучшится — но и не ухудшится заметно, а килобайт станет на порядок меньше.

Раскладка — папка на кейс, как в `src/images`:

```
src/media/webposter/drag.gif
src/media/webposter/scroll.mp4
```

`npm run media` соберёт из каждого мастера `mp4`, `webm` и кадр-заглушку в
`src/media/derived/**`. Эта папка в `.gitignore` и собирается заново перед
каждой сборкой — руками в ней ничего не лежит.

Путь пишется без расширения, от `src/media/`, и лежит **в словаре** — рядом
с подписью, потому что у русской и английской версии ролики разные:

```json
"drag": {
  "video": "webposter/drag-ru",
  "caption": "Зону сброса можно потрогать руками",
  "label": "Перетаскивание объекта в зону сброса"
}
```

В `src/content/cases/<кейс>.json` у блока остаются только тип, id и размер
слота:

```json
{ "type": "video", "id": "drag", "width": 756, "height": 425 }
```

Ролик, одинаковый для обоих языков, записывается в оба словаря одним и тем же
значением.

Как это устроено и что можно крутить — в `scripts/media.mjs`.
