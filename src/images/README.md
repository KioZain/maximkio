# Картинки

Сюда кладутся **мастера** — то, что вышло из экспорта, без ручного сжатия.
Папка на кейс:

```
src/images/webposter/filters-ru.png
src/images/webposter/filters-en.png
src/images/webposter/cover-un.png
```

Суффикс в имени — язык: `-ru`, `-en`, `-un` (одна и та же картинка на обоих
языках). Это соглашение об именах, а не механизм: какой файл уходит на каком
языке, решает словарь, см. `config/i18n/README.md`, «Что где живёт».

## Что отдавать

| Слот | Отрисовка | Мастер |
| --- | --- | --- |
| Картинка в кейсе | 756 px | 1512 px по ширине |
| Обложка кейса | 756×504, 3:2 | 1512×1008 |
| Карточка проекта на главной | 3:2 | 1512 px по ширине |
| Фотографии «о себе» | 684 px | 1368 px по ширине |
| Портрет в цитате | 40 px кругом | 80×80 |
| Портрет в профиле | 100 px | 200×200 |

Формат мастера на выдачу не влияет: наружу уходят только avif и webp.
Поэтому PNG для скриншотов, JPG качества 90+ для фотографий — важно лишь
чтобы исходник был не пережат.

Больше 1512 px смысла нет: упрётся в `max-width: 756px` в вёрстке.

## Команда

```
npm run images
```

Соберёт avif и webp в двух плотностях в `src/images/derived/**`. Папка в
`.gitignore` и пересобирается перед каждой сборкой — руками в ней ничего не
лежит. Как это устроено и откуда берутся размеры слотов — в
`scripts/images.mjs`.

## Что не мастера

`icons/` и `sprites/` скрипт не трогает: первое — svg, второе — спрайт-лист,
который режет CSS по координатам, и любое изменение размера сдвинет кадры.
