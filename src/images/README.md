# Картинки

Сюда кладутся **мастера** — то, что вышло из экспорта, без ручного сжатия.
Папка на кейс:

```
src/images/webposter/filters-ru.png
src/images/webposter/filters-en.png
src/images/webposter/cover-un.png
```

Суффикс в имени — язык: `-ru`, `-en`, `-un` (одна и та же картинка на обоих
языках). Это соглашение об именах, а не механизм: какой файл уходит на каком
языке, решает словарь, см. `config/i18n/README.md`, «Что где живёт».

## Что отдавать

| Слот | Отрисовка | Мастер |
| --- | --- | --- |
| Картинка в кейсе | 756 px | 1512 px по ширине |
| Обложка кейса | 756×504, 3:2 | 1512×1008 |
| Карточка проекта на главной | 3:2 | 1512 px по ширине |
| Фотографии «о себе» | 684 px | 1368 px по ширине |
| Портрет в цитате | 40 px кругом | 80×80 |
| Картинка бегущей строки | 280 px по высоте | **560 px по высоте** |
| Портрет в профиле | 100 px | 200×200 |

Формат мастера на выдачу не влияет: наружу уходят только avif и webp.
Поэтому PNG для скриншотов, JPG качества 90+ для фотографий — важно лишь
чтобы исходник был не пережат.

Больше 1512 px смысла нет: упрётся в `max-width: 756px` в вёрстке.

## Команда

```
npm run images
```

Соберёт avif и webp в двух плотностях в `src/images/derived/**`. Папка в
`.gitignore` и пересобирается перед каждой сборкой — руками в ней ничего не
лежит. Как это устроено и откуда берутся размеры слотов — в
`scripts/images.mjs`.

## Бегущая строка на главной

Мастера лежат в `src/images/marquee/`. Слот у них задан **высотой** (280 px),
а не шириной: строка выравнивает картинки по высоте, ширину каждая держит
свою. Поэтому пропорция файла может быть любой — ничего не обрезается.

Гифки класть сюда можно. Скрипт сделает из них анимированный webp: тот же
`<img>`, никакого JS, но в разы легче. Два отличия от обычных картинок:

- **avif у них нет** — он не умеет анимацию. В разметке такой картинке
  `<picture>` не нужен, хватает одного `<img>`.
- **только одинарная плотность.** Кадров под сотню, ретина-вариант выходит
  в семь раз тяжелее, а на движущейся картинке мягкость не читается.

### Добавить или заменить картинку

Состав строки лежит в `src/content/marquee.json` — по строке на картинку:

```json
{ "type": "picture", "id": "art-clock", "width": 280, "height": 280 }
```

- **`id`** — имя файла в `src/images/marquee/`, без расширения. Больше имя
  нигде не повторяется: все адреса собираются из него.
- **`type`** — `picture` для обычной картинки, `animated` для бывшей гифки.
- **`width` / `height`** — размер на экране. Высота всегда 280, ширину
  печатает `npm run images`.

Порядок в массиве — порядок в строке. `top` и `bottom` — верхняя и нижняя.

Чтобы заменить картинку, достаточно поменять `id`. Размеры `width`/`height`
обязательны: картинки грузятся лениво, а у незагруженной нет своей ширины —
строка посчитала бы её по пустой коробке.

## Что не мастера

`icons/` и `sprites/` скрипт не трогает: первое — svg, второе — спрайт-лист,
который режет CSS по координатам, и любое изменение размера сдвинет кадры.
