# Картинки для превью ссылок

Это **готовые файлы**, а не мастера: они копируются в сборку как есть, под
теми же именами. Хэша в имени нет намеренно — адрес картинки уходит наружу,
к краулерам соцсетей и мессенджеров, и должен быть стабильным.

Размер — **1200×630** (пропорция 1.91:1), формат JPEG. Это то, что ждут
платформы; PNG в этом размере весит под полтора мегабайта и краулер его
качает медленно.

## Имена

`<id страницы>_<язык>.jpg`, где в id слэш заменён на дефис:

```
index_ru.jpg
cases-webposter_ru.jpg
cases-artovoe.jpg          одна на оба языка
```

Имя не выводится автоматически — оно прописано в словарях,
`pages.<id>.image`. Так видно, какая картинка уйдёт на каком языке, и можно
поставить одну на оба или развести их.

## Что здесь сейчас

Всё, кроме этого файла, собрано кропом из обложек кейсов — чтобы превью
заработали сразу. Это заглушки: на превью попадает середина обложки без
подписей. Нормальная картинка для шеринга обычно несёт название проекта
крупным текстом — её стоит нарисовать отдельно и просто положить сюда под
тем же именем.
